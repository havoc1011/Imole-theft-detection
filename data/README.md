# Data

No data is committed to this repository.

## Simulated data
Generated on the fly by `src/imole_sim.py`. Nothing to download.

## SGCC public dataset (baseline study)
State Grid Corporation of China dataset: daily consumption for 42,372 customers (Jan 2014 – Oct 2016), 3,615 labelled thieves.
Download it from https://github.com/henryRDlab/ElectricityTheftDetection. The repo holds a split archive (`data.zip`, `data.z01`, `data.z02`).
Extract `data.csv` to `data/sgcc/data.csv`.

## DisCo or station records
Real utility records (billing, vending, feeder or transformer readings, inspection outcomes) must **never** be committed.
Use them only under a written data-sharing agreement, anonymised, and in line with the Nigeria Data Protection Act 2023.
